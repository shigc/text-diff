Инструмент сравнения текстов, **полностью работающий на стороне клиента**, вдохновлённый Beyond Compare. Все вычисления выполняются в браузере, и **текст никогда не отправляется на сервер** — можно безопасно вставлять конфигурации, логи и договоры.

## Возможности

- **Два режима просмотра**: параллельный (split) и объединённый (unified) с подсветкой различий на уровне символов
- **Навигация по различиям**: переход к предыдущему / следующему изменению и подсчёт добавленных, удалённых и изменённых строк в реальном времени
- **Параметры сравнения**: игнорировать пробелы, игнорировать регистр, показывать пробельные символы
- **Гибкий ввод**: вставка, выбор файла или перетаскивание в область редактирования
- **Экспорт в один клик**: HTML-отчёт / PDF / CSV
- **Многоязычный интерфейс**: китайский (упрощённый и традиционный), английский, японский, корейский, испанский, французский, немецкий, русский, португальский — переключение мгновенное, выбор запоминается
- **Минимум зависимостей**: единственная зависимость во время выполнения — [jsdiff](https://github.com/kpdecker/jsdiff); результат сборки — чисто статические файлы

## Локальная разработка

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev        # сервер разработки, по умолчанию http://localhost:5173
```

Основные команды:

```bash
npm run build            # строгая проверка типов через tsc + production-сборка
npm run preview          # локальный предпросмотр сборки
npm run typecheck        # только проверка типов
npm run lint             # ESLint
npm run format           # форматирование Prettier
npm run build:obfuscated # сборка с обфускацией JS (по умолчанию отключена)
```

Production-сборка по умолчанию **не** обфусцируется, чтобы код оставался читаемым и проверяемым. Если нужна обфускация при деплое, задайте `OBFUSCATE=1` или запустите `npm run build:obfuscated`.

## Развёртывание на Cloudflare Pages

### Вариант 1: интеграция с Git (рекомендуется)

Подключите этот репозиторий в Cloudflare Pages со следующими настройками:

| Параметр         | Значение        |
| ---------------- | --------------- |
| Framework        | Нет (None)      |
| Build command    | `npm run build` |
| Output directory | `dist`          |
| Node version     | 20              |

Каждый push в `main` будет разворачиваться автоматически. `public/_headers` применяется и добавляет к сайту CSP и другие заголовки безопасности.

### Вариант 2: командная строка

```bash
npx wrangler login   # авторизация в браузере или API-токен
npm run deploy       # сборка + деплой
```

Для API-токена скопируйте `.env.example` в `.env` и заполните:

```dotenv
CLOUDFLARE_API_TOKEN=ваш-api-токен
CLOUDFLARE_ACCOUNT_ID=идентификатор-аккаунта
CF_PAGES_PROJECT=text-diff
CF_PAGES_BRANCH=main
```

`npm run deploy` читает `CF_PAGES_PROJECT` / `CF_PAGES_BRANCH` из `.env`, поэтому после форка достаточно изменить имя проекта. `.env` исключён через `.gitignore` и никогда не попадает в репозиторий.

## Конфиденциальность

- Вся обработка текста происходит во вкладке браузера, эндпоинта для загрузки не существует
- Нет скриптов аналитики, трекинга, рекламы и сбора ошибок; страница не обращается к сторонним ресурсам
- В `localStorage` хранится только выбранный язык интерфейса
- Экспортированные файлы создаются локально и сохраняются только по нажатию кнопки скачивания

## Поддержка браузеров

Только современные браузеры (две последние мажорные версии Chrome / Edge / Firefox / Safari). Цель сборки — ES2020, IE не поддерживается.
